# java-http-framework
Comprendre les fondamentaux du web en construisant chaque couche à la main :
- TCP/IP et le protocole HTTP
- Routing et middlewares
- Architecture en couches (SOLID, Clean Architecture)
- Concurrence et thread pools

# stack
Java 17+

# commandes
javac -d out src/com/framework/core/*.java
java -cp out com.framework.core.HttpServer
